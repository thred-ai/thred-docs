## 1. Get your API key

Create a key in [Dashboard](https://dashboard.thred.ai) → Settings → API keys, then set it in your terminal:

```bash
export THRED_API_KEY="YOUR_API_KEY"
```

## 2. Create a search

```bash
curl https://api.thred.dev/search \
  -H "Authorization: Bearer $THRED_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "Where can I buy a Nintendo Switch 2 in Austin today?",
    "results": 2
  }'
```

The response returns a search `id`. Copy it into `THRED_SEARCH_ID` below.

## 3. Read the results

```bash
export THRED_SEARCH_ID="SEARCH_ID_FROM_CREATE_RESPONSE"

curl "https://api.thred.dev/search/$THRED_SEARCH_ID/results" \
  -H "Authorization: Bearer $THRED_API_KEY"
```

Read answers from `content`, for example:

> Example Electronics has the Nintendo Switch 2 in stock for pickup today until 6 p.m. Central Time.

This is a fictional example. Results also include source details and supporting evidence.

Searches run asynchronously. Repeat the GET while `terminal` is false. Pass `next_cursor` as `cursor` to continue from the last page, and read remaining pages while `has_more` is true.

See [Create a search](/api-reference/create-search) for options and [Get search results](/api-reference/search-results) for the response fields.
