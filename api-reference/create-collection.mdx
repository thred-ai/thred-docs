openapi: "api-reference/openapi.json POST /v1/collect"

Use the [quickstart](/quickstart) to set your API key. JavaScript uses Node.js; Python uses Requests.

`input` holds context values for the call. `output` is the JSON Schema defining the answers you want back in `data`. `input` is optional and defaults to an empty object.

<RequestExample>
```bash cURL
curl --fail-with-body https://api.thred.dev/v1/collect \
  --request POST \
  --header "Authorization: Bearer $THRED_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "to": "+14155550123",
    "instructions": "Ask whether the business is open on the date in input and what time it closes.",
    "input": { "date": "today" },
    "output": {
      "type": "object",
      "properties": {
        "is_open": { "type": "boolean" },
        "closes_at": { "type": "string" }
      },
      "required": ["is_open", "closes_at"],
      "additionalProperties": false
    }
  }'
```

```javascript JavaScript
const response = await fetch("https://api.thred.dev/v1/collect", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.THRED_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    to: "+14155550123",
    instructions: "Ask whether the business is open on the date in input and what time it closes.",
    input: { date: "today" },
    output: {
      type: "object",
      properties: {
        is_open: { type: "boolean" },
        closes_at: { type: "string" }
      },
      required: ["is_open", "closes_at"],
      "additionalProperties": false
    }
  }),
});

if (!response.ok) throw new Error(await response.text());
const collection = await response.json();
console.log(collection.id);
```

```python Python
import os
import requests

response = requests.post(
    "https://api.thred.dev/v1/collect",
    headers={
        "Authorization": f"Bearer {os.environ['THRED_API_KEY']}",
    },
    json={
        "to": "+14155550123",
        "instructions": "Ask whether the business is open on the date in input and what time it closes.",
        "input": { "date": "today" },
        "output": {
            "type": "object",
            "properties": {
                "is_open": { "type": "boolean" },
                "closes_at": { "type": "string" }
            },
            "required": ["is_open", "closes_at"],
            "additionalProperties": False
        }
    },
    timeout=30,
)
response.raise_for_status()
collection = response.json()
print(collection["id"])
```
