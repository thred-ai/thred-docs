---
title: "Get a search"
openapi: "api-reference/openapi.json GET /search/{id}"
---

Read a search's status and progress using the `id` returned at creation. Set `THRED_SEARCH_ID` to that ID before running the example:

```bash
export THRED_SEARCH_ID="SEARCH_ID_FROM_CREATE_RESPONSE"

curl "https://api.thred.dev/search/$THRED_SEARCH_ID" \
  -H "Authorization: Bearer $THRED_API_KEY"
```

The example response shows a completed search with two published results. Retrieve the answers from [Get search results](/api-reference/search-results).

## Status and progress

`discovering` and `running` indicate active work. `completed` means all selected results have finished processing, and `terminal` is true. Results are also readable while the search runs.

`published_results` counts available results. `requested_calls` is the original call cap; `selected_businesses` counts selected sources. `attempted_calls` and `answered_calls` track execution, including automated answering systems. `discovery_shortfall` reports how many requested sources could not be selected.

A terminal search can also be `failed`, `canceled` or `expired`. Inspect `error` and `stop_reason` when present. Individual results have their own statuses, so a completed search does not guarantee a complete answer from every source.
