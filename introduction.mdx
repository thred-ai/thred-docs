---
title: "Search with Thred"
description: "Find answers that aren't readily available online."
---

Thred is a search API that retrieves information over the phone. Ask a question in plain language, and Thred finds relevant sources and calls them to get the information you need.

Use it to check current stock, confirm availability, or get details that aren't published online.

Send a query to `/search`. The `results` field limits how many sources Thred attempts to contact:

```json
{
  "query": "Where can I buy a Nintendo Switch 2 in Austin today?",
  "results": 2
}
```

Searches run in the background. Read answers as they become available, with source details and supporting evidence from the conversations. Add optional `output` fields when you need structured data.
