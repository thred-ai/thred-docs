Thred calls a phone number, asks for the information you need, and returns the answers as JSON. Check business hours, ask about availability, or collect information that lives on the other end of a phone call.

## How it works

1. **Tell Thred what to ask.** Send a phone number and instructions.
2. **Choose your output.** Define the JSON fields you want back.
3. **Get the answers.** Save the call ID and retrieve the result when it is ready.

Thred handles the conversation and phone menus, and can request human assistance when needed.

## API at a glance

| You want to… | Endpoint |
| --- | --- |
| Start a call | [POST /v1/calls](/api-reference/create-call) |
| Read its status and result | [GET /v1/calls/&#123;id&#125;](/api-reference/get-call) |
| List your calls | [GET /v1/calls](/api-reference/list-calls) |
| Stop a call | [POST /v1/calls/&#123;id&#125;/cancel](/api-reference/cancel-call) |
| Check your usage | [GET /v1/usage](/api-reference/get-usage) |

The base URL is `https://api.thred.dev`. Use a bearer API key from the [dashboard](https://dashboard.thred.ai) to authenticate.
