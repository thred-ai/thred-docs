Read the current snapshot using the search `id` returned at creation. This endpoint returns the same response as [Get search records](/api-reference/search-results).

| Status | Meaning |
| --- | --- |
| `running` | The search is still working. Continue polling. |
| `completed` | The search finished with at least one supported answer. |
| `failed` | The search finished without a supported answer. Check `error`. |

Completion means an answer was found, even if some requested facts remain unknown. A deadline or cancellation with retained answers also returns `completed`, without an error.

A successful read returns HTTP `200`, including when the saved search has `status: "failed"`. See [Search errors](/guides/errors) for error codes.

Search IDs begin with `sch_`. Older `search_` IDs remain accepted in search lookup and cancellation routes; responses return the canonical `sch_` ID.
