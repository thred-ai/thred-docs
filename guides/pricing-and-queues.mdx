Thred costs **\$0.15 USD per returned record**.

## What is a record?

A record is one source's answer to your query, gathered over the phone. It appears in `records` with source details and evidence supporting the answer.

One record can contain several facts. A source that confirms availability, price and pickup hours produces one record.

## What counts?

| What the source provides | Records | Cost |
| --- | --- | --- |
| Answers to all requested facts | 1 | \$0.15 |
| Answers to some facts, with others still unknown | 1 | \$0.15 |
| A confirmed negative answer, such as “That item is unavailable” | 1 | \$0.15 |
| No supported answer, including only a refusal or “I don't know” | 0 | \$0.00 |

For example, a search that contacts 5 sources and returns 3 records costs **\$0.45**. If no records are returned, the cost is **\$0.00**. Reading the same search again does not create new charges.

## Search limits

Set `results` from **1–10** to limit how many distinct sources a search can call. The number of returned records depends on how many sources provide supported answers.

| Plan | Default search starts per minute |
| --- | --- |
| Free | 5 |
| Pay as you go | 30 |

These allowances are shared across your workspace's API keys and environments. Pay as you go requires an eligible saved card.

## Queued searches

Accepted searches return `202` and remain `running` while waiting to start or make calls. Work proceeds as capacity becomes available.

Each search has **two hours from acceptance**, including time spent waiting. At the deadline, unfinished work stops and supported answers already collected are retained.

Use [Get a search](/api-reference/get-search) to read the current status and records. See [Search errors](/guides/errors) for error handling.
