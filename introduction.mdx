Thred is a search API that retrieves information over the phone. Send a natural-language query from your app, and Thred calls relevant sources to get the answers.

```json
{
  "query": "Where can I buy a Nintendo Switch 2 in Austin today?",
  "results": 2
}
```

Read answers as they become available, with sources and supporting evidence from the calls. Add optional `output` fields when your app needs structured data.

[Make your first request](/quickstart).
