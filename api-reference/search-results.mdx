---
title: "Get search results"
openapi: "api-reference/openapi.json GET /search/{id}/results"
---

Read answers in `results[].content`, with source details and supporting `evidence`. Requested structured fields appear in `output`.

Pass `next_cursor` as `cursor` to read the next page. Keep polling while `terminal` is false; finish reading when `terminal` is true and `has_more` is false. Results arrive as they become available, with their relevance `rank` preserved.

An answer can be partial or null. Check `content` and any requested `output` fields before using them.
