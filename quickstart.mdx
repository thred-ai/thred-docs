Create a search, wait for its results and read the answers. This example uses Node.js with built-in `fetch`.

## Set your API key

Create a key in [Dashboard](https://dashboard.thred.ai) → Settings → API keys for your selected environment, then set it in your terminal:

```bash
export THRED_API_KEY="YOUR_API_KEY"
```

Your key selects the workspace and environment. See [Authentication](/api-reference/authentication) for setup and key verification.

## Create a search and read its answers

Save the following as `search.mjs`. It submits a query, follows the returned search ID and prints each answer as it becomes available.

```javascript
const apiKey = process.env.THRED_API_KEY;
if (!apiKey) throw new Error("Set THRED_API_KEY before running this example.");
const headers = { Authorization: `Bearer ${apiKey}` };

async function readJson(response) {
  if (!response.ok) throw new Error(await response.text());
  return response.json();
}

const search = await readJson(await fetch("https://api.thred.dev/search", {
  method: "POST",
  headers: { ...headers, "Content-Type": "application/json" },
  body: JSON.stringify({
    query: "Where can I access historical maps of Toronto, and do I need an appointment?",
    results: 2,
  }),
}));

let cursor;
while (true) {
  const url = new URL(`https://api.thred.dev/search/${search.id}/results`);
  url.searchParams.set("limit", "10");
  if (cursor) url.searchParams.set("cursor", cursor);
  const page = await readJson(await fetch(url, { headers }));
  for (const result of page.results) {
    if (result.content !== null) console.log(result.content);
  }
  cursor = page.next_cursor;
  if (page.terminal && !page.has_more) {
    console.log(`Search status: ${page.status}`);
    break;
  }
  if (!page.has_more) await new Promise(resolve => setTimeout(resolve, 3000));
}
```

Run it:

```bash
node search.mjs
```

Creation returns HTTP `202`. The script reads paginated results until the search finishes and every available page has been read. A completed search can produce answers like these fictional examples:

```text
Historical maps of Toronto can be viewed in the Example City Archives reading room; no appointment is required.
Historical maps of Toronto are available in the Example Reference Library special collections room; an appointment is required.
Search status: completed
```

Each result also includes source details, relevance `rank` and supporting `evidence`. See [Get search results](/api-reference/search-results) for the full response.
