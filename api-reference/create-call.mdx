---
title: "Create a call"
openapi: "api-reference/openapi.json POST /v1/calls"
---

Use the [quickstart](/quickstart) to set your API key and idempotency key.

<RequestExample>
```bash cURL
curl --fail-with-body https://api.thred.dev/v1/calls \
  --request POST \
  --header "Authorization: Bearer $THRED_API_KEY" \
  --header "Content-Type: application/json" \
  --header "Idempotency-Key: $THRED_REQUEST_ID" \
  --data '{
    "to": "+14155550123",
    "instructions": "Ask whether the business is open today and what time it closes.",
    "output_schema": {
      "type": "object",
      "properties": {
        "is_open": { "type": "boolean" },
        "closes_at": { "type": "string" }
      },
      "required": ["is_open", "closes_at"],
      "additionalProperties": false
    }
  }'
```
</RequestExample>
