---
title: "What you can build"
description: "Turn questions that require a phone call into structured answers."
---

Give Thred a phone number, a question to answer, and the shape of the result you need. Your application gets structured JSON after the call finishes.

## Useful calls to automate

| Use case | What to ask |
| --- | --- |
| Business hours | Confirm opening hours, holiday hours, or the latest pickup time. |
| Product availability | Ask whether a specific item is in stock and what it costs. |
| Appointment information | Ask about availability, accepted appointment types, or what a customer needs to bring. |
| Department questions | Reach the right department or extension and ask about its services. |

## Example: check inventory

Send this body to [Create a call](/api-reference/create-call), replacing `to` with the number you want to call:

```json
{
  "to": "+14155550123",
  "instructions": "Ask whether the store has a 6-foot USB-C charging cable in stock. If it does, ask for its price in USD.",
  "output_schema": {
    "type": "object",
    "properties": {
      "in_stock": {
        "type": "boolean",
        "description": "Whether a 6-foot USB-C charging cable is currently in stock."
      },
      "price_usd": {
        "type": ["number", "null"],
        "description": "The quoted price in USD, or null if the cable is unavailable."
      }
    },
    "required": ["in_stock", "price_usd"],
    "additionalProperties": false
  }
}
```

Thred returns a call ID immediately. [Retrieve the call](/api-reference/get-call) to check its status. Once `status` is `completed`, `data` contains the answers in your requested shape. If the result is `incomplete`, check `partial_data` for the answers it collected.

## Shape the answers

Use strings, numbers, integers, booleans, objects, and arrays in `output_schema`. Fields can also allow `null`, as the price does above. Give fields clear descriptions and list the answers you need under `required`.

The root must be an object. Every object needs `properties` and `additionalProperties: false`; arrays need an `items` schema. Thred supports a small JSON Schema subset. The [API reference](/api-reference/create-call) lists the supported fields.

## Add context and routing

| Option | Use it to |
| --- | --- |
| `input` | Provide known details, such as a product name or reference number. |
| `navigation` | Specify a contact name, department, extension, or language. |
| `max_duration_seconds` | Set how long the call can run within your workspace's limit. |
| `metadata` | Attach your own identifiers so you can match the result to a record in your app. |
| `webhook_id` | Receive a signed completion event at an endpoint configured in the dashboard. |

Start with the [quickstart](/quickstart), then add these options as your workflow needs them.
