## 1. Get your API key

Create a key in [Dashboard](https://dashboard.thred.ai) → Settings → API keys, then set it in your terminal:

```bash
export THRED_API_KEY="YOUR_API_KEY"
```

## 2. Create a search

```bash
curl https://api.thred.dev/search \
  -H "Authorization: Bearer $THRED_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "Where can I buy a Nintendo Switch 2 in Austin today?",
    "results": 2
  }'
```

`results` accepts 1–10 and limits how many distinct sources Thred can call. The API returns HTTP `202` with a search `id` beginning with `sch_`. Copy that ID below.

## 3. Read the answers

```bash
export THRED_SEARCH_ID="SEARCH_ID_FROM_CREATE_RESPONSE"

curl "https://api.thred.dev/search/$THRED_SEARCH_ID/results" \
  -H "Authorization: Bearer $THRED_API_KEY"
```

Read answers from `records[].content`, alongside their sources and supporting evidence. For example:

> Example Electronics has the Nintendo Switch 2 in stock for pickup today until 6 p.m. Central Time.

Repeat the GET while `status` is `running`. Stop when it becomes `completed` or `failed`. Each response contains the full current set of records, so replace the previous snapshot instead of appending it.

See [Create a search](/api-reference/create-search) for options and [Get search records](/api-reference/search-results) for response fields. All examples use fictional sources.
