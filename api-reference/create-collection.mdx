title: "Create a collection"
openapi: "api-reference/openapi.json POST /v1/collect"
---

Use the [quickstart](/quickstart) to set your API key. JavaScript uses Node.js; Python uses Requests.

`input` holds optional context for the call. In `output`, map each answer name to `string`, `number`, `integer`, or `boolean`. Thred expects all declared answers and returns their values in the collection's `output`.

<RequestExample>
```bash cURL
curl --fail-with-body https://api.thred.dev/v1/collect \
  --request POST \
  --header "Authorization: Bearer $THRED_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "to": "+14155550123",
    "instructions": "Ask whether the business is open on the date in input and what time it closes.",
    "input": { "date": "today" },
    "output": {
      "is_open": "boolean",
      "closes_at": "string"
    }
  }'
```

```javascript JavaScript
const response = await fetch("https://api.thred.dev/v1/collect", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.THRED_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    to: "+14155550123",
    instructions: "Ask whether the business is open on the date in input and what time it closes.",
    input: { date: "today" },
    output: {
      is_open: "boolean",
      closes_at: "string"
    }
  }),
});

if (!response.ok) throw new Error(await response.text());
const collection = await response.json();
console.log(collection.id);
```

```python Python
import os
import requests

response = requests.post(
    "https://api.thred.dev/v1/collect",
    headers={
        "Authorization": f"Bearer {os.environ['THRED_API_KEY']}",
    },
    json={
        "to": "+14155550123",
        "instructions": "Ask whether the business is open on the date in input and what time it closes.",
        "input": { "date": "today" },
        "output": {
            "is_open": "boolean",
            "closes_at": "string"
        }
    },
    timeout=30,
)
response.raise_for_status()
collection = response.json()
print(collection["id"])
```
