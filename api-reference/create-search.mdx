---
title: "Create a search"
openapi: "api-reference/openapi.json POST /search"
---

Send a natural-language `query` and a `results` count from 1 to 100. Thred searches for answers and publishes results with supporting evidence automatically.

`results` caps call attempts, including unanswered calls and negative responses. It is not a minimum number of matching answers. The endpoint returns HTTP `202`; use the returned `id` to read [progress](/api-reference/get-search) and [results](/api-reference/search-results).

## Example request

<CodeGroup>
```bash cURL
curl https://api.thred.dev/search \
  -H "Authorization: Bearer $THRED_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: maps-search-001" \
  -d '{
    "query": "Where can I access historical maps of Toronto, and do I need an appointment?",
    "results": 5,
    "timezone": "America/Toronto"
  }'
```

```javascript JavaScript
const response = await fetch("https://api.thred.dev/search", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.THRED_API_KEY}`,
    "Content-Type": "application/json",
    "Idempotency-Key": "maps-search-001",
  },
  body: JSON.stringify({
    query: "Where can I access historical maps of Toronto, and do I need an appointment?",
    results: 5,
    timezone: "America/Toronto",
  }),
});
if (!response.ok) throw new Error(await response.text());
const search = await response.json();
console.log(search.id);
```

```python Python
import json
import os
from urllib.request import Request, urlopen

request = Request(
    "https://api.thred.dev/search",
    method="POST",
    headers={
        "Authorization": f"Bearer {os.environ['THRED_API_KEY']}",
        "Content-Type": "application/json",
        "Idempotency-Key": "maps-search-001",
    },
    data=json.dumps({
        "query": "Where can I access historical maps of Toronto, and do I need an appointment?",
        "results": 5,
        "timezone": "America/Toronto",
    }).encode("utf-8"),
)
with urlopen(request) as response:
    search = json.load(response)
print(search["id"])
```
</CodeGroup>

Use the same idempotency key and identical request when retrying. A changed request with the same key returns `409`. Omitting the header creates a new search on each POST.

## Optional structured output

Without `output`, each result contains its answer as text in `content`. Add described fields when you also need structured values:

```json
{
  "query": "Where can I access historical maps of Toronto, and do I need an appointment?",
  "results": 5,
  "output": {
    "appointment_required": {
      "type": "boolean",
      "description": "Whether an appointment is required to access historical maps of Toronto."
    },
    "access_details": {
      "type": "string",
      "description": "How to access the maps, including any registration or visit requirements."
    }
  }
}
```

Each field needs a `type` and a nonempty `description` of up to 1,000 characters. Supported types are `string`, `string[]`, `number`, `integer` and `boolean`. Supply at most 20 fields and 12,000 characters of output-definition JSON. Results include structured `output` only when requested; unsupported answers remain unknown.
