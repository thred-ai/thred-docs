---
title: "Search with Thred"
description: "Ask a question and get answers with sources and supporting evidence."
---

Thred is a search API. Send a natural-language query and read the answers as they become available.

```json
{
  "query": "Where can I access historical maps of Toronto, and do I need an appointment?",
  "results": 2
}
```

Results include text answers, sources and supporting evidence. Add optional `output` fields when you need structured data.
