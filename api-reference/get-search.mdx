---
title: "Get search progress"
openapi: "api-reference/openapi.json GET /search/{id}"
---

Read the state of a search using the `search_` ID returned at creation.

```bash
curl https://api.thred.dev/search/search_YOUR_SEARCH_ID \
  -H "Authorization: Bearer $THRED_API_KEY"
```

`requested_calls` is the original call cap. `selected_businesses` counts the businesses selected by discovery; `attempted_calls`, `answered_calls` and `published_results` track execution. Answered calls can include automated answering systems. `discovery_shortfall` reports when fewer eligible businesses were found than requested.

Continue polling until `terminal` is true. Terminal statuses are `completed`, `failed`, `canceled` and `expired`. A completed search means its outcomes have settled; individual businesses can still have negative answers, partial answers or unsuccessful calls.

Read published answers through [Get search results](/api-reference/search-results), including while other calls are still running.
