---
title: "Search for answers by phone"
description: "Ask a question. Thred finds relevant businesses and calls them."
---

Send a query and the number of business calls to make. Thred discovers relevant businesses with verified phone numbers, generates questions, calls them, and returns concise text answers in `content` with transcript evidence.

```json
{
  "query": "Which dentists in Toronto accept new patients and have appointments this week?",
  "results": 10,
  "timezone": "America/Toronto"
}
```

`results` is a hard cap on distinct-business call attempts. Unanswered calls and negative responses count. Successful matches are not guaranteed, and Thred reports when discovery finds fewer eligible businesses. Reading another result page never starts more calls.

Each new search obtains fresh answers through its calls. Phone numbers are discovered by Thred; the request only requires `query` and `results`.

Searches are asynchronous. Create a search, read progress, then retrieve paginated outcomes. Each call is finalized automatically, and its answer becomes available as soon as processing finishes.

| Endpoint | Purpose |
| --- | --- |
| `POST /search` | Start a search. |
| `GET /search/{id}` | Read progress and call counters. |
| `GET /search/{id}/results` | Read published business outcomes. |
| `POST /search/{id}/cancel` | Stop remaining work and retain published answers. |

Results include the business, its text answer in `content`, call status, transcript `evidence` and discovery `sources`. If no supported answer is available, `content` is null. Supply optional `output` fields when you also need structured values.
