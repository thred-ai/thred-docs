Thred collects information over the phone and returns structured JSON.

Use the **Collect API** when you know who to ask. Provide a phone number, instructions, and an output schema. Thred makes the call and gets the answers: business hours, inventory, availability, and more.

## How it works

1. **Choose the source.** Send the phone number you want Thred to call and what you want to find out.
2. **Choose your output.** Define the JSON fields you want back.
3. **Get the answers.** Save the collection ID and retrieve the result when it is ready.

Thred handles the conversation and phone menus, and can request human assistance when needed.

## Collect API at a glance

| You want to… | Endpoint |
| --- | --- |
| Start a collection | [POST /v1/collect](/api-reference/create-collection) |
| Read its status and result | [GET /v1/collect/&#123;id&#125;](/api-reference/get-collection) |
| List your collections | [GET /v1/collect](/api-reference/list-collections) |
| Cancel a collection | [POST /v1/collect/&#123;id&#125;/cancel](/api-reference/cancel-collection) |
| Check your usage | [GET /v1/usage](/api-reference/get-usage) |

The base URL is `https://api.thred.dev`. Use a bearer API key from the [dashboard](https://dashboard.thred.ai) to authenticate.
